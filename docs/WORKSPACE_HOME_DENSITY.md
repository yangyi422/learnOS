# 首页布局比例、内容密度与操作位置

## 检查与范围

已检查首页模板/样式、PageShell、AppShell、ui-design及既有浏览器测试。原创造/探索均为全宽长条；项目网格会横向展开，箭头占最右列，学习操作与文字分离。痕迹行padding和字距造成密度偏低。

本轮业务代码仅WorkspaceHomeView.vue，不修改AppShell、PageShell、全局主题、光层、后端、API或数据库。保留此前未提交工作。项目选择/焦点规则、真实数据、捕获、导航、加载/重试与图片行为均不变。

## 规则

- 首页宽度不变，建立home-layout inline-size查询容器。内容宽度>=960px时创造/探索各span6、顶部对齐、间隔24px，各按内容自然占高；不足时全宽。>=900px时第一排保持8:4，低于该值改为单栏。手机既有内容顺序保留。
- 项目为一列紧凑行，图标/名称/摘要保留，箭头与名称间8px，长名称正常换行，不为单项目预留额外行高。
- 学习图标靠上，标签→可换行20px标题→两行14px问题摘要→13px状态→继续入口。整块仍可点击原课程/地图，摘要title及原课程提供完整内容。没有复制或修改课程正文。
- 痕迹全宽，行min-height64px、上下10px、标题15px/来源日期13px，通常约67px；长标题不截断，内容宽度<=600px时日期移至第二行。时间右对齐、箭头统一列。
- 保留所有环境光与主卡透明渐变/模糊，主卡最突出。创造/探索弱边框，痕迹再弱一级透明表面与边框。深色辅助文字从#AFA0C0提亮至#BCB0CB，卡片及文字整体opacity不变。面板内边距24px、主卡28px（手机24px）。
