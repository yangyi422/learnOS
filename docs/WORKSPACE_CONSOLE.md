# Wope 个人控制台：AppShell 与首页样板

## 范围与依据

用户明确要求明显的视觉重设计，Wope Style Reference 为本轮唯一视觉方向。上一轮仅主题变量和基础控件不足以建立控制台的视觉重心。本轮调整组件结构和信息比例，只涉及 AppShell、WorkspaceHomeView、相关测试与文档。未修改后端、数据库、API、任务选择规则、计数、排序、财务隐私、权限或业务路由。此前未提交的其他页面改动保持原样，没有在本轮继续推广。

## 结构

首页继续使用 PageShell，标题32px、手机28px，日期作为次要信息，快速记录复用原Dialog/API。12列桌面布局：焦点8列/Today4列，项目7列/学习5列，最近内容横跨页面并使用3列来源卡。1024px保留桌面并列比例、更窄窗口折为2列；手机单列依次焦点、Today、学习、项目、最近内容与档案入口。

焦点有状态头、真实项目上下文、独立标题/说明与底部行动区。项目从逐行列表变为最多5个可点击小卡，仍展示真实进行中/下一步/未完成数量，不计算新百分比。学习使用带领域标识、当前课题、核心问题、理解状态和继续操作的主题卡，不增加虚构进度或装饰统计。最近记录仍按原日期规则取最多6条，保留真实来源链接及私有封面缩略图；财务只展示入口和快照日期。所有空态、骨架、模块错误、重试、保存失败保留输入与未保存确认继续沿用。

## 材质与光线

- 画布 #0a0118，导航 #130c22，焦点正文稳定底色 #1c1032；导航与面板有明确边界。
- Today/项目使用 rgba(31,21,49,.78)，辅助来源卡使用3.5%白色膜；导航选中有渐变光带，顶栏与Today采用局部backdrop blur。
- 首页背景有紫色径向环境光，焦点外缘有经24px模糊的紫色光场；不透明内层覆盖正文区域，避免光晕影响文字对比度。
- 主要行动使用紫色光边与胶囊形，辅助操作使用透明胶囊。项目/学习/最近内容保留不同的信息结构和比例，不共用一种平铺列表。
- 样板材质变量定义在组件作用域；深色祖先选择器编译后仍限定组件，避免作用于所有页面。阅读、Markdown、密集表格没有新增环境光。AppShell导航与顶栏外观作为共享壳保持一致。
- 无运行时几何计算、动态光效、外部字体/图片服务、额外框架或AI数据传输。用户显式主题选择保留，浅色模式提供可用回退。

## 验证

相同合成数据在1920/1440/1024/390px保存修改前截图（console-before）与修改后截图；包含3个项目、真实格式的Today与学习记录、4个最近来源，不写入正式数据库。材料断言检测实际渲染的画布与导航色、径向环境光、焦点光场、不透明文字底色、半透明Today/模糊、项目和来源网格、胶囊形以及减少动态效果。浏览器测试复用已有项目、学习、Inbox、生活、财务、Wiki/Cards与导航用例。

检查截图时发现Vue scoped的 :global(ancestor) 会丢掉尾部选择器，导致主题变量定义在根节点后被组件默认值覆盖；已换成可正确编译的主题祖先+组件选择器。检查同时调整手机区域标题对齐，保持标题与操作左/右基线。

最终类型检查、16个文件35项单元测试、生产构建与git diff --check通过；全站165项Playwright通过（5.3分钟，无重试）。最后根据1024px截图把项目统计移到卡片底部独立三列，随后首页全部28项再次通过，最终类型检查与构建再次通过。构建仍保留既有大包警告。已实际查看1920/1440/1024/390px的首页截图。焦点辅助文字在稳定底色上的理论对比度6.31:1，主操作白字5.51:1；浏览器同时验证既有浅深色语义对比度与2px焦点。

相同数据前后截图位于git忽略的 data/design-previews/console-before-{width}.png 和 console-after-{width}.png；原始最终截图在 web/test-results/console-home-final，完整回归在 console-final。截图是实际组件渲染，内容为隔离合成数据，并非正式用户档案。尚需Windows字体、触屏、非Chromium与真实私人内容密度人工检查；未进行服务端/数据库修改，无需迁移。本轮不部署或推送。
