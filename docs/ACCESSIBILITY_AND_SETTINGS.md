# 视觉、无障碍与系统设置契约

## 范围

本阶段只统一展示术语、语义色、导航与表单语义，并完善既有系统设置能力。课程生成、当前课程节点、学习评价、探索推荐和掌握度计算均未改变。

## 视觉与术语

- 蓝色：当前状态与主要操作。
- 绿色：成功、完成或掌握。
- 黄色：生成中、发展中或待确认。
- 紫色：探索方向和跨领域发现。
- 灰色：未接触、未知、暂停或忽略。
- 红色：失败、冲突或拒绝。

界面统一使用“待生成节点”“知识层级”“迁移挑战”“我的理解”“课程节点”“证据关联”等中文名称；服务商、模型名、API Key、DOI、ISBN 等通用技术名称保留。正文辅助色在白色背景上的 WCAG 对比度为 4.76:1（`#64748b`）或 7.58:1（`#475569`）。

## 无障碍语义

- 桌面和移动菜单使用 `nav` landmark 与真实 `RouterLink`；当前页面标记 `aria-current="page"`。
- 移动抽屉打开后焦点进入首个链接，Escape/遮罩可关闭；关闭后焦点返回菜单按钮或新页面一级标题。
- 新建领域字段错误通过 `aria-invalid` 和 `aria-describedby` 关联；错误文本使用 `role="alert"`。
- AI 连接、保存、备份、恢复和一致性检查结果通过 `aria-live="polite"` 播报。
- 所有键盘可操作元素共享清晰的 `focus-visible` 外框；图标按钮和重复操作使用包含对象语境的可访问名称。

## AI 设置与密钥边界

Provider 与 Model 分开选择。配置接口只返回 `api_key_configured`，绝不返回 API Key；连接测试只使用后端已生效配置，并只返回 Provider、Model、检查时间和耗时。客户端不会把 Key 写入 localStorage、URL 或测试快照，后端错误也不会包含 Key 或上游响应正文。

## 安全恢复

1. 用户只能从服务端列出的备份中选择，不能提交任意路径。
2. 必须逐字输入 `恢复 <文件名>`。
3. 后端校验备份并固定快照，避免保留策略在恢复前淘汰所选文件。
4. 应用优雅关闭 HTTP 与 SQLite，交给进程管理器重启。
5. 启动时、打开数据库前，为当前数据库创建安全备份，再原子替换并复验完整性。
6. 失败标记会归档，不会循环重启；任何失败都不会主动删除现有学习数据。

## 验证

- Vitest：领域表单、节点类型、知识筛选和布局单元测试。
- Go：AI 配置脱敏、连接测试、备份验证、恢复确认、恢复前保护与保留策略边界。
- Playwright：键盘导航、`aria-current`、错误关联、`aria-live`、密钥不落页面/响应/控制台、安全恢复确认及 375/768/1024/1440 横向溢出。

尚需人工验收真实屏幕阅读器朗读顺序、操作系统高对比模式，以及真实 DeepSeek 网络环境中的连接错误文案。
