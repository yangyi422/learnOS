# LearnOS 界面设计规范

LearnOS 是个人学习、探索和项目管理空间。界面采用**极简未来感个人工作空间**的方向：信息清楚、操作明确、材质克制。此文档约束后续前端设计决策；现有主题实现与已完成的看板细节见 [WORKSPACE_VISUAL.md](WORKSPACE_VISUAL.md)。

## 视觉语言

- 深色使用深蓝黑画布、略亮的石墨蓝内容表面、冷白正文和中性灰辅助文字；浅色使用冷白画布、白色表面、深墨正文和灰色辅助文字。画布、内容表面、浮层应有可辨的层次。
- 电蓝用于主要操作与选中态；蓝青色仅用于少量交互高光或状态。细边框、轻阴影和局部冷色渐变服务于内容，不持续发光或叠加大面积装饰。
- 主标题、任务名称和正文使用中性主文字；标签、项目、日期与记录使用两级中性灰。蓝色不承担普通辅助文字的层级表达，只用于操作、链接、选中和焦点。
- 优先使用 `web/src/workspace-theme.css` 的语义变量管理背景、文字、边框、强调色、阴影和圆角，并保持两种主题独立校准的文字对比度。
- 外观主题（跟随系统、浅色、深色）集中放在系统设置中；工作区顶栏保持位置提示和必要上下文，不放置页面级主题切换控件。
- 中文优先使用清晰的无衬线字体回退；图标保持统一线性风格、尺寸和线宽。

## 布局与信息层级

- 使用轻量导航、紧凑标题区和清晰工具栏；外层内容边距在页面间保持一致，内层宽度由阅读或操作任务决定。看板便于扫描，学习页便于阅读，探索页便于发现。
- 桌面应用采用悬浮式外壳：外围约 12～16px 留白，窄导航轨道与主工作区之间约 10～12px 间距。主工作区是独立的低对比细边框表面，位置提示顶栏属于该表面；窄屏收小外围留白。不要把每个内容区继续包成面板。
- 避免重复标题、重复操作入口、巨大空容器和为填满屏幕而增加的内容。页面标题通常为 26～32px，正文通常为 14～16px，辅助信息通常为 12～13px；按内容密度和视口调整。
- 卡片通常使用 6～10px 圆角和适度内边距，避免层层卡片嵌套。看板使用开放式分列，让任务卡片成为视觉主体。
- 看板任务卡片按标题、可选摘要、底部项目与日期组织信息；整张卡片按住即可拖动，拖动状态与打开详情的点击操作保持清晰区分。详情抽屉是任务编辑区：标题优先、属性紧凑、记录可折叠，正文滚动时底部操作仍可访问。
- 属性分组优先以轻背景形成关系，不额外叠加完整边框。输入控件保留低对比边界，悬停稍加强，聚焦使用清楚的电蓝焦点；正文式标题输入也必须通过悬停和聚焦反馈表达可编辑性。
- 空白状态提供一个明确说明和一个主要行动入口。加载失败与真实空数据要区分；不凭空创建进度、推荐或示例内容。
- 首次使用页把欢迎标题、简短说明与唯一主操作整合为一个视觉整体，放在工作区中上部；留白应帮助聚焦，而不产生无意义滚动。

## 交互与工作方式

- 悬停、选中、键盘焦点和拖拽状态清楚一致。短促微动效表达交互，并遵守系统的减少动态效果偏好。
- 卡片与控件状态过渡通常为 120～160ms，抽屉开合通常为 160～180ms；只过渡实际变化的属性，不使用 `transition: all`。卡片悬停以边框、表面和轻阴影反馈，不做明显位移。
- 抽屉及通过 Teleport 挂载的菜单、日期面板和确认弹窗使用根节点主题变量；关闭有未保存修改的任务时，应先确认是否放弃。
- 深浅主题分别校准抽屉遮罩和边缘阴影，让背景上下文仍可辨认。长说明在限定行数内随内容增长，超过后内部滚动；字数提示在聚焦或接近上限时出现。抽屉打开后焦点进入标题，关闭后回到触发入口。
- 先检查现有页面、组件和真实数据状态，再确定布局与信息层级，最后打磨颜色、边框和材质。优先复用共享组件和主题变量，保留业务逻辑、权限、路由及已有功能。
- 有浏览器能力时，以隔离测试数据运行页面并查看深浅主题截图，修正溢出、错位和对比度。构建通过只说明代码可构建，不代替视觉验收。
