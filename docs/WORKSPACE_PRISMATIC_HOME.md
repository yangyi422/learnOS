# B 方案首页：棱光学习工作台

日期：2026-10-16。选定构图：[B 桌面参考](../design/home-concepts-2026-10-16/violet-study/b-1440x1080.png)。本文记录实际前端实现，替代前序文档中的首页构图与字阶说明，保留原有数据契约。

## 范围与实现

仅调整 `/` 的布局、材质、字体与首页交互。`web/src/components/AppShell.vue` 为首页提供76px横向顶栏，其他业务页保留侧栏；小于1180px时横向导航收为原导航抽屉。快速记录和用户菜单继续复用现有能力，主题选择保持原行为。没有后端、数据库迁移或部署变更。

`web/src/views/WorkspaceHomeView.vue` 使用桌面1:1.3:1三列、24px列间距：左侧项目与今天，中间重点与最近内容，右侧继续学习。内容宽度上限1680px。701–1099px使用两列，学习跨列；700px及以下改为重点→今天→学习→项目→最近内容，快捷入口随后展示。面板随真实内容增长，不以参考图固定文本或高度。

`web/src/components/HomeLightField.vue` 只渲染一次共享光场，以低强度宽扁径向渐变在重点卡下部提供背光，不渲染弧线；装饰层不接收点击，并对辅助技术隐藏。光源位置随三列、两列和手机布局调整。面板为16px圆角、14px背景模糊，基础细边连续，局部反光不代替轮廓。`web/src/workspace-theme.css` 在现有主题中定义 `--home-*`，不新增全局主题系统。

## 字体与主题

中文优先字体栈为 PingFang SC、Microsoft YaHei、Noto Sans CJK SC、WenQuanYi Zen Hei、system-ui、sans-serif。桌面首页标题44px/1.4、重点36px/1.5、课题28px/1.6；手机分别28px/1.5、26px、21px。中文不使用营销标题的负字距。

深色画布 #09051B、主文字 #F2EDF9、链接 #C9B3FF；浅色画布 #F4F3FA、主文字 #2B233A、链接 #6942B2。主题分别校准透明膜、边缘和光强。主行动保持紫色白字，辅助文字独立取色，不通过容器透明度降低可读性。保留键盘焦点反馈与减少动态效果偏好。

## 数据与操作边界

首页继续读取真实工作区及最近内容API，不使用参考图里的示例事实。重点理由、日期和状态来自当前任务或学习位置。今日列表最多显示三项真实任务，按紧迫程度排序；只说明真实到期信息，不添加虚构的日程时刻。任务与项目入口继续打开原详情或页面。

项目进度分母为 `open_task_count + done_task_count`，分子为 `done_task_count`；零任务时不显示进度比例。最近内容仍合并资料库、生活事件和目标阶段变化，最多六条，日期明确说明更新、发生或变化含义。加载、空数据、局部失败与刷新失败继续分别处理。

顶部搜索仅在已加载的当前重点、今日任务、项目、学习和最近内容标题中筛选，最多八项；任务按ID去重并避开已列为重点的任务。它不是服务端全库搜索，也不搜索未加载正文。手机隐藏该搜索框。快速记录继续复用既有弹层与保存后刷新流程。

## 验证记录与边界

本轮前端类型检查、35项单元测试及生产构建已通过。浏览器回归共91项：全量运行89项通过，2项旧字号断言已同步为44px；随后重跑相关12项全部通过（8项深浅主题/尺寸、2项对比度与焦点、2项边缘连续性）。Safari、Firefox和真实触屏设备尚需复核。

设计辅助流程的 build 阶段停在 stuck plates，因其独立审批门槛未解除，产出资产为零；没有强制批准或绕过审批。页面实现采用现有组件、CSS光场及学习几何SVG。最终1440×1080实页对照已导出，像素比较仍标记 drift，包含真实内容、导航及动态高度适配差异；未补造历史 hero 阶段证据。该情况不等于完整机械设计流程通过，本次只记录实际已实现和已验证的结果。


## 安静背光专项修订

本次只修改 HomeLightField、首页背光定位与环境光 tokens，并移除焦点/学习卡独立的边缘反射伪元素；不改布局、内容、字体、业务操作及数据读取。移除SVG弧线与白色亮核。唯一低饱和扁椭圆位于重点卡后方偏下，桌面中心为网格50%/310px，两列改25%/310px，手机为50%/300px。中心18%保持低强度平台，外围缓慢衰减，避免可见的聚光中心。深色主色rgba(104,78,145,.22)，衰减rgba(82,59,119,.08)；浅色分别为rgba(137,116,174,.13)、rgba(123,106,158,.05)。原有面板透明度、微弱表面明度变化和基础细边保留。环境反射token同步降低，主操作按钮与文字保持原有对比度。

实际浏览器验收对比开/关光效截图，验证今日重点优先、学习和项目为第二层，并检查光层移除不改变内容几何或操作。

专项验收：12项浏览器检查通过（8项深浅主题/尺寸及开关光效对比、2项对比度与焦点、2项基础边缘连续性）。截图在 `design/home-concepts-2026-10-16/quiet-backlight/`。两份独立复核均未发现本次光效范围内的视觉问题；复核使用父流程生成的实际 Playwright 截图，未宣称已进行浏览器叠层检测。

浅色玻璃验收：12项浏览器检查、类型检查、生产构建通过；覆盖1920/1440/1024/390px与深浅主题、关光对照、对比度及轮廓连续性。精修后实页截图存于 `design/home-concepts-2026-10-19/light-glass-neon/`。深色环境背景仍为#09051B、主按钮仍为#713DFF，未新增光域。

### 2026-10-19：玻璃反射与导航中轴

浅色首页降低普通面板填充至.14，重点表面.24→.12；背景增加宽斜向亮区及局部青蓝/淡紫色场，配非对称内边缘反射，避免将白边浅色填充当作透明玻璃。正文仍为深墨色，深色主题材质不变。

### 2026-10-19：首页色系自定义

首页个人菜单加入「首页外观」，所有登录用户均可打开无背景遮罩的侧边设置，支持深/浅/系统模式、默认及冰川蓝/极光紫/玫瑰/松石绿预设与原生取色器。即时应用，只保存当前浏览器 localStorage `learnos-home-accent`；不写学习数据或后端。色系只影响首页环境色、背光、链接及主按钮，不改透明材质、布局、导航中轴或其他业务页面。恢复默认清除自定义变量并还原深浅主题原设计。

持久化只接受完整六位十六进制颜色，非法存储回退默认；禁用存储时仍即时预览并显示无法保存提示。同源多标签同步storage事件。自定义主按钮按相对亮度选择黑/白前景，单元测试覆盖4096种颜色，保证正常状态文本对比度≥4.5:1。无彩色自定义保留零饱和度，避免灰白颜色错误生成红色背景。浅色/深色各自使用固定亮度、透明度范围映射环境色，保留正文对比度。

色系设置验收：37项单元测试、5项浏览器场景、类型检查和生产构建通过。覆盖正常偏好持久化、默认回退、主题切换、自定义亮色黑字、普通用户权限、存储异常提示、桌面和手机面板。实页截图 `design/home-concepts-2026-10-19/appearance-control/`。本轮未部署。


### 2026-10-19：自然边缘环境光

自然环境光验收：15项相关浏览器检查、类型检查和生产构建通过，覆盖深浅六档尺寸、调色恢复与对比度。实页截图 `design/home-concepts-2026-10-19/natural-light/`。遵照用户偏好自动部署。
