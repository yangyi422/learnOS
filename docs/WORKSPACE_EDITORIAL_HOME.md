# Editorial Home：个人操作系统首页

## 本轮范围

用户要求首页更接近个人操作系统而非后台数据看板。本轮业务代码仅修改 WorkspaceHomeView.vue；AppShell、PageShell、全局主题、其他业务页、Go、数据库、API与路由均没有继续修改。已有未提交改动不清理、不重写。规范按用户最新首页要求覆盖此前首页Wope样板的卡片与发光约束，其他页面继续使用原规范。

## 信息架构

- “今天，想专注什么？”：当前日期和原有快速记录。
- “当前旅程”：原任务/学习焦点、真实项目与状态、优先级/到期信息和继续入口。仅展示名称改变，不新建旅程表、不改变焦点排序。
- “今天”：先展示最多三个真实优先事项，再以小字号说明原进行中/到期/下一步数量，不展示大数字KPI。
- “正在创造”：最多5个活跃项目，用标题与原描述为主；没有描述时根据原任务状态提示“正在推进”或“有下一步可以继续”，不推测成果或完成百分比。点击仍打开原项目看板。
- “正在探索”：最近课程、当前课题、核心问题和学习状态，以阅读段落与继续链接呈现，课程跳转与进度数据不变。
- “最近留下的痕迹”：复用原最近内容聚合，最多6条资料/生活/目标变化；按原更新时间或发生日期排序，并明确标注日期含义。使用开放行与来源图标/私有缩略图，保留原URL。
- 页尾保持Inbox待整理、资料库、生活与财务入口。财务仍只显示快照日期，不显示金额。

## 双主题与布局

Light主内容暖纸 #F7F6F2，墨色 #292822、次文字 #68645C、辅助 #756F66；Dark主内容 #19161F，暖白 #EEE9E2、次文字 #C0B8C6、辅助 #AAA2B1。强调为灰紫，主操作反差清楚，不使用浮层投影或环境光。局部变量只声明在首页，背景选择器只匹配现有 app-shell--home 路由类，进入其他页面即失效；已保存主题选择保持不变。

保留PageShell的共同水平基线，首页内部12列开敞布局：旅程8/Today4，创造7/探索5，痕迹全宽。区域间距36～48px，内容通过字重、阅读宽度与留白组织。仅保留Today旁一条细纵线及痕迹分区前一条轻横线，不为每个内容单位加四边框。手机依次旅程、今天、探索、创造、痕迹和入口。

去除原矩形模块背景、玻璃材质、焦点边缘光晕和每条记录的完整边框。学习主题为无边框阅读区域；项目为紧凑目录，痕迹为开放时间记录。私有图片继续用原缩略图、懒加载和异步解码，加载失败与原文引用机制不改。

空态、骨架、模块错误及重试、捕获成功刷新数量、失败保留输入、未保存关闭确认沿用。触发元素继续是原生button或RouterLink，焦点与登录保护不变；未将测试数据写入正式数据库。

Windows字体、真实触屏、Firefox/Safari和真实私人大量内容仍需人工验收。没有新增字体/依赖，未执行后端测试（本轮未改后端），没有部署或提交推送。
