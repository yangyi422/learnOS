# 项目执行中心初版

> 此文档记录 Schema 16 的历史设计。现行看板语义和 Schema 17 迁移见 [PROJECTS.md](PROJECTS.md)。

## 定位与边界

项目执行中心只回答“现在推进什么”：项目标题与状态、任务标题与状态、一个明确的下一步行动。它不承载笔记正文，也不与 Obsidian 同步。课程和学习数据保持独立；既有学习首页不变。

## 状态与操作

- 项目状态：`active`、`paused`、`completed`；完成后仍可重新设为进行中。
- 任务状态：`todo`、`doing`、`done`；完成后可重新打开。
- 每个项目最多一个下一步行动；只有未完成任务能设为下一步。完成或删除该任务会清除标记，但不会自动替用户选择另一项。
- 项目可创建、重命名和切换状态；本版不提供项目删除，已完成状态用于留存历史。任务可创建、重命名、切换状态和删除；删除需要确认。

## API 与数据安全

所有接口位于 `/api/v1/projects` 下并使用现有会话认证。列表只返回当前用户的项目和任务。项目/任务写入必须同时校验用户、项目 ID 与任务 ID；跨用户访问返回 404，不暴露资源是否存在。输入标题会去首尾空格，拒绝空值与超长值；状态只接受约定枚举。数据库唯一索引与事务共同维护下一步行动不变量。

Schema 16 只新增两张表和一个部分唯一索引。生产升级前自动备份既有 SQLite；JSON/Markdown 导出也包含项目数据。本版不做提醒、日历、AI 自动操作或笔记同步。
