# 首页持续环境光与玻璃材质

## 原因与范围

已阅读DESIGN.md、ui-design、PageShell、AppShell、首页与全局主题。当前document为滚动容器（由浏览器测试验证）；原光源只有旅程下沿的绝对定位伪元素，随主卡离开视口，且首页主动关闭环境光。旅程内部实色遮光层进一步阻挡透光。

本轮仅在AppShell增加首页专属、aria-hidden的非交互fixed背景层，并修改首页局部材质、相关测试及文档。固定层位于app-content独立层叠上下文中z=0，透明main-content为z=1；导航和顶栏保留现有层级。固定层inset:56px 0 0 var(--sidebar-width)，自然适配224/64/0px侧栏。没有监听scroll、布局测量、额外滚动容器或background-attachment。

## 材质

深色画布#0A0118；偏右15%紫色、左下12%淡紫的大范围径向渐变。浅色画布#F5F6FB，两处更淡的紫色与冷白光。普通卡片深色rgba(18,10,32,.55)、浅色rgba(255,255,255,.60)，14px模糊。旅程使用透明渐变，取消实色遮光；局部下沿光的尺寸和位置不变。普通卡片没有外发光。上沿稍亮/下沿稍暗，hover改变背景与边框，不上浮，180ms且遵守reduced-motion。

只模糊外层表面，不对卡片整体设置opacity，不叠加子组件模糊；子行背景继续透明。布局、业务、API、数据库、隐私策略与路由保持不变。不支持backdrop-filter时保留透明填色和边框。
