# 首页：品牌恢复与 Editorial + Panel Hybrid

## 范围

上一轮过度去卡片化削弱了品牌氛围。本轮在现有首页架构上恢复视觉承载，不重排业务模块、不恢复大数字统计、不增加新功能。业务代码仅修改 WorkspaceHomeView.vue；AppShell/PageShell、全局theme、Go、SQLite、API和其他页面不改。已有未提交改动保持原样。

## 容器与层次

保留“今天，想专注什么？”、当前旅程/今天、正在创造/正在探索、最近留下的痕迹和原快捷入口。旅程为主视觉surface，Today为较轻辅助surface，创造采用边界很弱的整区surface，探索采用淡紫/深紫surface，痕迹合并成一块安静面板。项目与痕迹内部仍是开放条目，没有为每项加四边框；创造按内容高度收束，避免少量项目产生等高空盒。

描边为紫色低透明度，圆角18～20px；环境光只在首页背景和旅程边缘。旅程通过不透明内层阻挡光晕进入文字区，按钮有小范围紫色光，不使用传统黑色大阴影或动态粒子。浅色是相同品牌角色的对应版本，保留暖纸底色而非纯白后台。

仍使用同一PageShell水平基线和12列布局，模块间距24～28px，标题32/28px。手机沿用旅程→Today→探索→创造→痕迹→入口，边距22px并保留主要按钮44px触达。颜色变量只在首页，主容器背景和ambient规则只匹配 app-shell--home，导航到其他页面立即恢复原样。

## 业务与验证

原焦点选择、Today排序、项目最多5条、学习继续、最近来源最多6条、日期口径、私有缩略图、快速记录、错误重试、未保存确认和财务只展示日期保持。本轮没有正式数据库写入，也没有新增依赖、字体服务或AI请求。

最终截图为实际组件配合隔离合成数据渲染，保存在git忽略的 data/design-previews/home-layered-{theme}-{width}.png；原始测试结果在 web/test-results/layered-final。
