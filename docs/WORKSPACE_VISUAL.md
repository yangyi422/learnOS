# 个人数字工作空间视觉基线

## 范围

本版统一应用外壳与项目看板视觉。桌面采用带外围留白的悬浮式工作区，76px 图标导航成为独立轨道，位置提示顶栏属于主工作区；外观主题选择集中在系统设置页，避免顶栏出现页面级控制。移动端保留原导航抽屉与焦点返回行为。项目页把标题、项目选择和新建任务放在同一行，视图切换单独置于下方轻量工具栏。看板保留原有项目筛选、视图、任务抽屉、整卡拖动和分页操作，不改变业务接口或数据。

## 主题

`web/src/workspace-theme.css` 定义外部画布、工作区、内容表面、文字、边框、强调色、阴影和圆角变量，并映射到 Element Plus 的常用变量。浅色主题使用极淡冰蓝外围、冷白工作区、白色任务卡和银灰边框；深色主题使用深蓝黑外围、略亮的工作区与石墨蓝卡片。电蓝承担主要操作，蓝青色用于导航指示线和少量状态。顶栏局部使用轻微模糊，工作区上边缘有很淡的冷色高光。

主题选项为跟随系统、浅色、深色，默认跟随系统。选择保存在浏览器 `localStorage` 的 `learnos-theme`；手动选择优先于系统设置，系统模式会响应操作系统主题变化。主题仅是本机显示偏好，不进入 SQLite 或任务 API。

## 交互与后续

桌面导航项使用统一线性图标、浏览器原生悬停提示和可访问名称；原生提示不占侧栏滚动宽度。选中态使用纤细蓝青指示线和淡蓝背景。看板采用开放式分列与轻分隔线，没有整列实色面板；卡片悬停时轻微提亮边框，聚焦和拖动时显示更明确的状态。每列的添加任务入口紧随任务列表，空列保留可拖放区域。窄屏可横向滚动看板；减少动态效果偏好会关闭装饰性动效。

其他页面接入基础主题与控件配色。本版未逐页重绘旧学习模块；少数知识图与旧状态面板仍可在下一轮统一其细节样式。
