# LifeOS V0.2-C：长期目标的财务参考

长期目标详情增加“财务参考”：选择已有资产快照，可填写判断日期及最多 1000 字关联说明。默认日期为浏览器本地当天，与快照日期分别保存。说明可以为空，不修改目标状态、当前判断或阶段记录，不自动计算目标进度。正式决策仍由原有变化历程记录。

## 数据与维护

Schema 24 新增 `goal_asset_references`，包含 ID、目标 ID、快照 ID、说明、判断日期、version、创建/修改时间。目标和快照 ID 联合唯一，一个目标可以引用多份快照，一份快照可以被多个目标引用。不复制金额。

- 所有接口认证并校验双方归属。创建在事务中验证父记录，唯一索引防止重复；同内容重试返回已有记录，不同内容返回冲突，必须明确编辑。
- 编辑及解除要求 version，防止旧表单覆盖新说明。修改说明保留建立时间；解除只删除关联及其说明，不删除目标、阶段记录或快照。
- 已引用快照阻止删除，提示先在目标中解除关联。SQLite 外键同样使用 RESTRICT，防止直接删除产生悬空引用。
- 目标目前没有删除入口，继续使用“已结束”状态保留历史。如果实际删除目标，外键 CASCADE 清理财务关联，快照不删除；本轮不新增目标删除 UI/API。
- 快照编辑后关联 ID 继续有效，目标读取最新保存的快照数据，说明不变。详情标注快照最后修改时间，并提示当前金额可能已经修订；不提供资产版本历史。
- 快照完整性及金额计算沿用资产服务。未填类别保留 NULL；不完整范围使用“已填资产合计”“已填范围差额”，未知金额显示未记录，不称完整净资产。

## 交互与导航

目标详情内完成选择、确认、编辑说明和解除，不新增快照。选择列表标明日期与范围，选中后显示资产、负债及差额。单份可选快照自动选中，但必须手动确认保存。失败保留输入，保存时禁用重复提交，未保存关闭提示放弃。

查看快照导航到 `/life/finance?tab=assets&asset=ID`，关闭目标弹窗后使用原资产详情，不嵌套弹窗。携带生活来源和 return_goal，返回生活可恢复原目标。资产详情仅在有引用或请求状态时显示反向目标入口，点击 `/life?view=goals&goal=ID` 打开原目标详情；没有第二套目标管理。

## API 与备份

- `GET /api/v1/life/goals/:id/assets`
- `POST /api/v1/life/goals/:id/assets/:assetId`，输入 note、judgment_date
- `PUT` 同路径，另需 version
- `DELETE` 同路径，查询参数 version
- `GET /api/v1/finance/assets/:id/goals`

服务端拒绝未知字段、无效日期、非法 ID、超长说明及跨用户父记录。仓储禁用 SQL 日志，财务关联路径与财务路径均不记录访问内容和异常堆栈。不调用 AI 或外部服务。

沿用启动前整库备份及可重复 AutoMigrate，不重写旧记录。SQLite 备份/恢复包含新表；JSON 导出增加 goal_asset_references，Markdown 导出目标/快照稳定 ID、判断日期与说明。

不开发阶段记录直接引用、资金进度、自动财务判断、资产版本历史或 AI 建议。
